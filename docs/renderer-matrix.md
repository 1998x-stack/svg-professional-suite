# Renderer Matrix

| Workload | Preferred tool | Alternatives |
|---|---|---|
| System architecture | D2 | Mermaid, PlantUML |
| Simple flow | Mermaid | Native SVG |
| Graph/dependency | Graphviz | Cytoscape.js |
| Scientific data | Matplotlib | Vega-Lite |
| Mathematical figure | TikZ/PGF | Native SVG |
| Research schematic | Native SVG / Inkscape | TikZ |
| Timeline | D3.js | Native SVG |
| Knowledge network | Cytoscape.js | Graphviz |
| Business chart | Vega-Lite | ECharts |
| Strategy framework | Native SVG | D2 |
| Logo/icon | Native SVG / Inkscape | Figma, Illustrator |

Only the native acyclic GraphSpec renderer and static validator are implemented in this repository. Other tools are optional external choices, not bundled integrations.
