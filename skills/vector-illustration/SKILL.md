# Vector Illustration

Define artboard, grid, optical alignment, stroke width, cap/join, corner radius, palette, negative space, and target sizes before drawing. Create concepts, refine geometry, and test legibility at actual display sizes, including favicon scale.

Prefer clean paths and simple shapes; avoid unnecessary filters and embedded raster images. Use consistent geometry across related assets. Add semantic title/description where useful. Record provenance and licenses for third-party icons, fonts, and illustrations.

Native SVG is suitable for simple assets; Inkscape, Figma, or Illustrator may be used for refinement. Lucide and Tabler are reference libraries subject to their licenses. Static output must not include scripts or external resources.
