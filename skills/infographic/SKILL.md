# Infographic

Start with the message the graphic should communicate. Separate facts, interpretation, chronology, causality, and uncertainty. Build hierarchy before drawing: headline, thesis, sections, evidence, annotations, and source notes.

Choose visual grammar based on information: timeline for chronology; typed graph for entities and relations; tree for taxonomy; process flow for steps; comparison matrix for alternatives; chart for quantities. Never imply causation from temporal sequence alone.

D3.js is suitable for custom editorial graphics, Cytoscape.js for networks, Graphviz for static graph layouts, D2/Mermaid for logic flows, and native SVG for final composition. External tools are optional.

Use clear reading order, restrained palette, legible labels, and traceable sources.
